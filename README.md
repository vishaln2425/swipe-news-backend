# 📰 Swipe News

A modern, mobile-first news app with vertical swiping like Instagram Reels, built using **Ionic + Angular** and powered by a **Node.js + TypeScript** backend.

![Swipe News Screenshot](https://github.com/user-attachments/assets/9501ea9c-e864-4d88-bc4c-e7f18a0c1f90)

---

## 🚀 Features

- Vertical swipe news feed using Swiper
- Admin panel to upload news
- Automatic image **resizing & WebP conversion** in backend
- Push-notification-ready
- Smooth UI with Lottie animations
- Hosted backend (Render)

---

## 🔧 Tech Stack

- **Frontend**: Ionic + Angular (standalone components)
- **Backend**: Node.js + TypeScript
- **Image Processing**: Sharp (WebP conversion)
- **Hosting**: Render
- **Animations**: ngx-lottie
